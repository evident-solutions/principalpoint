# Mortgage paydown planner

Single-page calculator for remaining term from a current statement balance, optional comparison to the original amortization, and future extra-payment plans. A plan is a strategy of recurring prepayments (a fixed extra or a monthly principal target) and lump sums. Two or more strategies compare side by side against the same baseline. Escrow is included in cash out the door but does not reduce principal.

```bash
npm install
npm test
npm run dev
```

Open the local URL Vite prints. There is no Calculate button — results update as inputs change.
